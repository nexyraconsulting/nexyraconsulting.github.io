Nexyra Consulting icon set

37 icons, drawn to the Lucide specification: 24x24 grid, 1.5px stroke, round caps and joins, no fill.
Stroke uses currentColor, so an icon takes the colour of its parent text.

Usage
  <img src="icons/arrow-right.svg" alt="" width="24" height="24">   (fixed colour: ink)
  Inline the SVG markup to inherit currentColor and allow violet accenting.

Icons are ink (#0A0A0F). Colour them violet (#7C3AED) only when they carry the action.
Geometry follows Lucide (ISC License).
