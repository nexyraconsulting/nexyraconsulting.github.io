Voice — we write

  • Plainly, in the active voice
  • Specifically — named outcomes, real numbers
  • Confidently, without superlatives
  • Short first sentence, detail after

Voice — we avoid

  • "Cutting-edge", "synergy", "leverage"
  • Hype about AI or technology for its own sake
  • Jargon a board member would have to decode
  • Exclamation marks, ever

Clear space

Keep clear space equal to the full height of the monogram on every side. Nothing — type, rules, image edges — enters this field.

Balance

60 ink · 30 neutral · 10 brand colour. If the violet is doing more than a tenth of the work, the layout is compensating for weak structure.

Contrast rules

  • Body copy on white: Ink #0A0A0F only.
  • #7C3AED on white passes for 18px+ and UI chrome — use #6D28D9 for small text.
  • On ink, links use #A78BFA, never #2563EB.
  • Never set the gradient behind body-size text.

Wordmark tracking is fixed. NEXYRA sits at +5.33/51 (≈0.105em) in Medium; CONSULTING at +9.67/16.1 (≈0.6em) in Regular. Never reset the wordmark by hand — use the supplied files.

Headlines go tight, labels go wide. Anything above 24px takes negative tracking; anything below 12px takes caps and +0.2em.

One weight per level. 600 for headings, 400 for copy, 500 for interface labels. Bold 700 is reserved for numerals in data.

Licensed substitute

Named in the logo files as the first fallback. Commercially licensed — it is not distributed in this package. Purchase per seat from the foundry and install locally; the CSS picks it up automatically if Hanken Grotesk is unavailable.

System fallback: Helvetica Neue, then Arial. No download required.

Implementation

How it is wired

All four files are declared in css/fonts.css as a single variable family with font-weight: 100 900 and font-display: swap, split by unicode range so latin pages load 34 KB.

05

Grid & space

8pt spacing scale

4 — icon gaps, inline nudges
8 — label to control
16 — inside components
24 — between components
48 — block separation
88 — section padding

12-column grid

Desktop 12 columns / 24px gutters / 7vw margins. Tablet 8 / 16. Mobile 4 / 16. Zero corner radius everywhere except the app icon.
