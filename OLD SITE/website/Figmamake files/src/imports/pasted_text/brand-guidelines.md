The brand book should be created as a **hidden/internal page within the same website**, accessible directly by entering:

**https://nexyraconsulting.co.uk/brand**

### 1. Preserve the existing website

Do not redesign or modify the existing public-facing website unnecessarily.

The Brand Book must:

* Use the existing Nexyra Consulting brand identity.
* Follow the existing logo, colours, typography, visual language and UI patterns.
* Maintain consistency with the current website.
* Act as the single source of truth for the website's visual and design system.

### 2. Hidden `/brand` route

Create a dedicated Brand Book page at:

**`/brand`**

The page should **not appear in the main website navigation, header, footer or sitemap-style navigation**.

It should only be accessible when the user directly enters:

**nexyraconsulting.co.uk/brand**

The page should still function as a normal responsive webpage once accessed directly.

Do not add a visible "Brand Book" link anywhere on the public website.

### 3. Create a comprehensive Brand Book

The `/brand` page should be professionally structured as a complete digital brand guideline and design system.

Include the following sections:

#### Brand Overview

* Nexyra Consulting brand introduction
* Brand purpose
* Brand positioning
* Brand personality
* Brand attributes
* Brand principles
* Visual identity overview

#### Logo System

Document the complete Nexyra Consulting logo system, including:

* Primary logo
* N monogram
* "Hairline into Gap" logo concept
* Full **N + NEXYRA CONSULTING** lockup (Copy the attached SVG logo lockup but use brand color)
* Horizontal lockup
* Stacked lockup, where appropriate
* Light-background version
* Dark-background/reversed version
* Monochrome version
* Minimum size
* Clear space
* Correct and incorrect usage
* Logo placement guidance
* Examples of acceptable backgrounds

Use the actual approved logo assets from the website/project rather than creating unrelated alternatives.

#### Colour System

Document the complete colour palette used by Nexyra Consulting.

For every colour provide:

* Colour name
* HEX
* RGB
* HSL, where useful
* Primary / secondary / accent classification
* Recommended usage
* Accessibility considerations

Show the colours visually using professional swatches.

Also define:

* Primary brand colours
* Secondary colours
* Neutral colours
* Background colours
* Text colours
* Border/divider colours
* Interactive states

Include UI states such as:

* Default
* Hover
* Active
* Focus
* Disabled
* Error
* Success
* Warning

#### Typography

Document the typography system currently used by the website.

Include:

* Primary typeface
* Secondary typeface, if applicable
* Heading styles
* Body styles
* Caption styles
* Button text
* Navigation text
* Labels
* Font weights
* Font sizes
* Line heights
* Letter spacing
* Responsive typography behaviour

Create clear visual examples of each typography style.

#### Spacing & Layout

Define the website's layout system, including:

* Spacing scale
* Container widths
* Grid system
* Columns
* Gutters
* Section spacing
* Padding
* Margins
* Border radius
* Breakpoints

Make these values reusable and consistent across the website.

#### UI Components

Create a complete component library based on the existing website.

Include, where applicable:

* Header
* Navigation
* Buttons
* Links
* Cards
* Forms
* Input fields
* Dropdowns
* Checkboxes
* Radio buttons
* Tabs
* Accordions
* Badges
* Alerts
* Modals
* Tooltips
* Footer
* Breadcrumbs
* Section headers
* Hero sections
* Content blocks
* Contact components
* Social media elements

For each component document:

* Anatomy
* Variants
* States
* Spacing
* Typography
* Colours
* Usage guidance

### 4. Responsive Design System

Document how the design system behaves across:

* Desktop
* Laptop
* Tablet
* Mobile

Define responsive:

* Breakpoints
* Typography changes
* Grid behaviour
* Component behaviour
* Spacing adjustments
* Navigation behaviour

Use a **mobile-first approach**.

### 5. Accessibility

Include accessibility standards and guidance for the design system.

Cover:

* Colour contrast
* Typography readability
* Focus states
* Keyboard navigation
* Touch target sizes
* Form accessibility
* Link accessibility
* Button accessibility
* Image alt-text guidance
* WCAG considerations

Aim for **WCAG 2.2 AA** compliance wherever practical.

### 6. Iconography & Imagery

Document:

* Icon style
* Icon sizing
* Icon spacing
* Icon usage
* Image treatment
* Photography direction
* Illustration style
* AI-generated imagery guidance, if applicable
* Image aspect ratios

Keep the visual language aligned with Nexyra Consulting's professional consulting/technology positioning.

### 7. Design Tokens

Create a structured design-token system for:

* Colours
* Typography
* Font weights
* Font sizes
* Line heights
* Spacing
* Border radius
* Shadows
* Borders
* Breakpoints
* Component states

Use meaningful token names such as:

`color-brand-primary`

`color-brand-secondary`

`color-text-primary`

`spacing-md`

`radius-lg`

`font-size-heading-xl`

These should be structured so they can be easily translated into CSS variables or a Figma design-token system later.

### 8. Content & Voice

Include a concise Nexyra Consulting content/voice section covering:

* Tone of voice
* Writing principles
* Heading style
* CTA language
* Professional terminology
* Do / Don't examples

The tone should feel:
**confident, intelligent, modern, trustworthy, professional and technology-led.**

### 9. Brand Book Navigation

The `/brand` page should have its own internal navigation so users can quickly jump between sections.

Suggested navigation:

**Overview | Logo | Colour | Typography | Layout | Components | Responsive | Accessibility | Icons & Imagery | Design Tokens | Voice**

Use sticky navigation where appropriate.

### 10. Visual Presentation

The Brand Book itself should look like a **premium professional design-system documentation site**, not a basic webpage.

Use:

* Clean editorial layouts
* Strong hierarchy
* Generous whitespace
* Visual examples
* Component demonstrations
* Colour swatches
* Typography specimens
* Responsive examples
* Clear section dividers
* Professional documentation styling

It should feel comparable to a professional corporate design-system / brand-guideline platform.

### 11. Important implementation requirement

The Brand Book must be implemented as a **real hidden route/page**, not simply a modal or section hidden on the homepage.

The final website structure should effectively be:

**Public website**
`https://nexyraconsulting.co.uk/`

**Hidden Brand Book**
`https://nexyraconsulting.co.uk/brand`

The `/brand` route must work when the URL is entered directly into the browser.

Do not expose the Brand Book through the primary website navigation.

### 12. Final requirement

Before completing the work:

1. Audit the existing Nexyra Consulting website.
2. Extract its existing visual language.
3. Identify the actual colours, typography, spacing and UI patterns.
4. Build the Brand Book around those existing principles.
5. Ensure the `/brand` page is visually consistent with the public website.
6. Do not invent a completely new visual identity.
7. Make the Brand Book responsive and production-ready.
8. Ensure all components and design tokens are clearly documented and reusable.

The final result should establish **Nexyra Consulting's ****`/brand`**** page as the authoritative Brand Book and Design System for the entire website.**
