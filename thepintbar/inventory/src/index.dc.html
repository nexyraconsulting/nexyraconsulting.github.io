Setting this up at the bar

One-time. Open this page in Chrome or Edge on the desktop, press Connect workbook above and choose data/inventory.xlsx from this package. Allow the browser to save changes when it asks. The file is now the database.

Every time after. Opening the page reconnects to the same file on its own. If the browser asks again after a restart, the amber bar offers a single Reconnect workbook click — you never have to find the file twice.

Sharing between computers. Put the workbook in a folder that syncs — OneDrive, Dropbox, Google Drive, or a shared network drive — and connect each computer to its own copy of that path. The page re-reads the file every few seconds, so one bartender's change reaches the others once the folder syncs.

Keep the workbook closed in Excel while the bar is trading — Excel locks the file and saves will fail until it is closed. A change that cannot be written is refused and reported, never silently lost.
